Install from your browser

  • Use Chrome or Edge on desktop (WebMIDI with SysEx is required).
  • Connect the FM-1 with a USB data cable and close any other app using MIDI.
  • Your browser will ask for MIDI access — approve it.

Good to know

  • This is a test build (device identity FM-1_990). It installs like any firmware and you can go back to stock anytime with M-VAVE's M-UPGRADE or the Firmware Hub.
  • Do not unplug while it is writing.
  • If the screen ever shows a crash report, the device restarts itself — that report is useful, send it our way.
  • Two failed boots in a row drop the FM-1 into USB rescue by itself; you can also hold OCT- while switching on.
  • If an install is interrupted, reconnect and use Resume interrupted update — the device stays in update mode until it finishes.
Maestro is built on the Dinghy template over Felucca. The browser update protocol (vendor/fm1ota.js) and package tools (vendor/fm1pkg.js) are by Leo Kuroshita / Hügelton Instruments, GPL-3.0, vendored verbatim. Maestro itself is GPL-3.0.
